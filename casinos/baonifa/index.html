5. 你自己還要確認的事

本站查證後仍無法確定的事

  • 官網最低儲值金額與首儲優惠具體數字在 JS 動態載入的商品清單中，指令列未取得。
  • 中時 2022-11-09 報導是否確實以「包你發」為標題與內文主體，需瀏覽器渲染後複核。
  • 官網明寫「非現金交易賭博」，但第三方排行榜將其與現金版娛樂城並列比較；其點數是否能經幣商換現，官方站無任何說明。

查證過程遇到的狀況

  • WebSearch 摘要與中時 2022-11-09 搜尋結果標題指稱有洗錢水房利用「包你發」遊戲幣洗錢，但該則新聞內文本次未能取得（JS 載入），無法逐字驗證；聯合報 2025-08-23 虛擬幣商洗錢報導亦因付費牆未能確認是否提及本品牌。
  • 第三方排行榜（havespring.com、brand-strategy.tw）指此類「幣商版」平台需經第三方幣商變現、存在匯差與被幣商詐騙風險，屬第三方說法（來源：comp/rank1.html、comp/rank7.html）。
  • Google Safe Browsing 未查（需 API 金鑰）。

不論哪一家都該做的四件事

  • 牌照：不看網站上的證書截圖，直接到發照機構的公開名單查。做法見牌照查真假。
  • 網域：只從你確認過的官方入口進站，任何用 LINE、簡訊丟給你的「新網址」都先當可疑。辨識方法見冒名詐騙站辨識。
  • 出金：先小額出一次確認流程，再決定要不要放大額。被要求先繳「保證金」「解凍金」才能出金，是 165 明列的詐騙特徵。
  • 帳戶：出金後若銀行帳戶被列警示戶，處理步驟見銀行警示戶自救。
