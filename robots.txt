# 娛樂觀察站 robots.txt
# 政策（2026-08-07 站長決定）：**開放引用，不開放訓練**。
#   - 引用／檢索（AI 回答時即時抓取並標註來源）→ 允許，這是本站存在的目的

# 每個 user-agent 在本檔案中只出現一次，不存在互相矛盾的指令。
#
# 分類依據：各家官方文件對自家爬蟲用途的說明
#   OAI-SearchBot／ChatGPT-User      OpenAI 的搜尋索引與使用者即時抓取 → 引用
#   GPTBot                            OpenAI 的訓練資料抓取           → 訓練
#   Claude-SearchBot／Claude-User    Anthropic 的搜尋與使用者抓取     → 引用
#   ClaudeBot                         Anthropic 的一般性抓取（含訓練）→ 訓練
#   PerplexityBot／Perplexity-User   Perplexity 的檢索               → 引用
#   Google-Extended                   控制 Gemini 訓練與 grounding    → 訓練
#     （注意：Google AI Overview 走的是一般 Googlebot，不受這條影響，
#       所以擋掉 Google-Extended 不會讓本站從 AI Overview 消失）
#   bingbot／Applebot                 一般搜尋索引（Copilot 引用來源）→ 引用
#   CCBot／Bytespider／Amazonbot／
#   Applebot-Extended／meta-externalagent                            → 訓練
#
# 維護提醒：如果線上 https://yuleguance.com/robots.txt 在本檔案內容之前
# 多出一段 Disallow 區塊（Content-Signal: ...ai-train=no,use=reference），
